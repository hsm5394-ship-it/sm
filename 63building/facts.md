# 63빌딩(63스퀘어) 사전 조사

조사일: 2026-11-12. 웹 검색 결과(검색 엔진이 돌려준 본문 발췌)를 근거로 정리했다.
이 작업 환경의 네트워크 정책 때문에 개별 페이지를 직접 열어 전문을 읽지는 못했다.

## 2. 출처 간 불일치 · 미확인 (자막에 넣지 않음)

- **설계 귀속**: Structurae는 설계자를 Harry D. Som / Helen W. Som으로 적고 "SOM 설계는 잘못된 귀속"이라고 한다. 국내 언론과 63스퀘어 측 설명은 SOM + 박춘명. → 영상 자막에는 설계사 이름을 넣지 않았다.
- **착공 연도**: Structurae는 1979년 착공으로 적는다. 국내 자료는 1980년 2월로 일치 → 1980 채택.
- **피어 수·지름**: "240여 개"(ZZNZ) vs "243개, 지름 4.5m"(위키백과). 지름 4.5m × 243개는 건물 평면에 비해 과도해 보여 지름 수치는 쓰지 않음. 자막은 "240여 개".
- **유리의 금 코팅**: 나무위키에는 "장당 금 0.5g" 등의 서술이 있으나 니켈 합금이라는 반론도 실려 있어 미확인. 자막은 "황금색 이중 반사유리"까지만.
- **코어 구성**: 코어의 정확한 치수·재료·가새 방식은 확인하지 못했다. 영상에서는 "엘리베이터·계단이 모이는 중앙 코어"라는 일반적 표현만 쓰고, 모델은 회색 중앙 샤프트로 단순화했다.
- **'기도하는 손' 형태 유래**: 나무위키 서술뿐이라 미사용.
- **철골 물량, 타워크레인 대수·사양, 층당 공사 속도, 터파기 깊이**: 확인 실패. 미사용.
- **전망대 층수, 엘리베이터 대수, 내풍·내진 수치(초속 40m 등)**: 1차 확인 부족. 미사용.
- **실제 시공 단계 순서**: 날짜가 확인된 것은 착공 → 골조(1983.5 40층 이상) → 상량(1983.11) → 외벽 완료(1984.7) → 준공(1985.5)뿐이다. 영상의 7단계는 이 뼈대에 일반적인 철골 고층 건물 시공 순서(터파기 → 기초 → 지하 → 골조 → 바닥·외벽 → 마감)를 입힌 **설명용 단순화**다. 실제 현장에서는 바닥판과 커튼월이 철골을 몇 층 뒤따라가며 동시에 올라간다.

## 3. 모델링 가정 (확인된 수치가 아님)

- 평면 크기와 단면 곡선: 사진상의 비례를 눈대중으로 맞춘 값이다(`config.json`의 `building.profile`). 기단부 약 78×54m → 최상부 약 72×21m로 가정.
- 층고 4.0m × 60층 = 240m + 옥탑 9m = 249m로 맞춤.
- 피어는 240여 개 대신 66개로 줄여 표현, 지하 3층 깊이는 15m로 가정.
- 주변 여의도 지형·건물·다리는 위치만 대략 맞춘 저채도 박스.
