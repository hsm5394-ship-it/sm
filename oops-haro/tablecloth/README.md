## 완성하는 순서

1. Seedance 등 이미지 참조가 되는 영상 모델에서 `00-locks.txt` + `clipA…txt`를 붙여 15초 생성 (참조 이미지 3장).
2. 클립 A의 마지막 프레임을 저장해 네 번째 참조로 넣고 `00-locks.txt` + `clipB…txt`로 15초 생성.
   모델이 15초를 못 만들면 각 Shot 블록을 따로 생성하고, 매번 직전 클립의 마지막 프레임을 시작 이미지로 씁니다.
3. 클립을 `clips/`에 넣고 `clips/manifest.txt`의 해당 줄 주석을 풉니다.
4. 실행:

```bash
python3 tools/score.py
```

```bash
tools/assemble.sh
```

5. `qc/sheet-*.png`를 보고, 효과음이 동작과 어긋나면 `timeline.json`의 `t`만 고쳐 4번을 다시 실행합니다.

## 결정이 필요한 것: 하로 의상

브리프는 "크림색 오리무늬 반팔 롬퍼 + 민트색 테두리"인데, 첨부된 하로 캐릭터시트는 **민트색 롬퍼 + 가슴의 노란 오리 패치 1개**입니다. 이미지 참조 모델은 글보다 그림을 따르므로 둘이 다르면 장면마다 의상이 흔들립니다.
프롬프트는 일단 **시트(민트 롬퍼)** 기준으로 썼습니다. 크림색이 맞다면 크림색 의상으로 된 새 시트가 필요하고, `00-locks.txt`의 `HARO_OUTFIT` 한 줄만 바꾸면 됩니다.

## 브리프에서 보완해 정한 것

- 장면 6에서 **하준이 접시와 컵**, **하나가 냅킨**을 듭니다. 장면 8에서 하준이 접시·컵을 되돌려 놓고 하나가 냅킨을 하로에게 건네야 소품이 순간이동하지 않습니다.
- 소품 색: 접시 연노랑, 컵 민트, 냅킨 흰색 (브리프에 색 지정이 없어 임의로 정함).
- 카메라는 항상 식탁 앞쪽, 빛은 항상 화면 왼쪽 창에서 들어옵니다.

## 검사하지 못한 것

영상이 없으므로 화면에 관한 항목(캐릭터 일치, 의상, 스타일, 인원, 소품, 동작, 장면 연결, 자막·로고)은 **하나도 검사하지 못했습니다.** 사운드는 길이·음량·무음 여부만 측정했고, 실제로 어떻게 들리는지와 동작과의 일치는 확인하지 못했습니다.
